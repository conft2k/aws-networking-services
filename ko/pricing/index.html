Elastic Load Balancing

로드 밸런서가 실행 중인 시간(부분 시간도 1시간)과 사용한 용량 단위(LCU)로 요금을 냅니다. LCU는 매시간 여러 차원 중 가장 많이 쓴 차원 하나로만 계산합니다. Classic Load Balancer만 LCU 대신 처리한 데이터 GB당 요금을 씁니다.

ALB · LCU

새 연결, 활성 연결, 처리 바이트, 규칙 평가 4개 차원 중 최댓값입니다.

NLB · NLCU

새 연결/flow, 활성 연결/flow, 처리 바이트 3개 차원이고 TCP·UDP·TLS 트래픽을 따로 계산해 더합니다.

GWLB · GLCU

새 연결/flow, 활성 연결/flow, 처리 바이트 3개 차원입니다. 시간당 요금은 AZ마다 부과합니다.

LCU 예약

미리 예약한 LCU는 사용 여부와 상관없이 시간당 부과하고, 예약량을 넘은 사용분은 일반 LCU 단가로 냅니다.

공식 요금 페이지

VPC Lattice

VPC Lattice service는 서비스 시간당 요금, 처리 데이터 GB당 요금, 요청(HTTP/HTTPS listener) 또는 TCP 연결(TLS listener) 수 요금 세 가지로 냅니다. service network에 붙인 VPC resource(resource configuration)는 resource 시간당 요금과 GB당 처리 요금이 따로 붙습니다.

Service hour

VPC Lattice service가 프로비저닝되어 있는 매시간(부분 시간 포함) 부과합니다.

Data processing

service가 받은 요청과 보낸 응답을 합친 GB당입니다. AZ 간 전송 요금은 따로 붙지 않습니다.

Requests · Connections

service마다 매시간 첫 30만 건은 무료(Always Free)이고, 넘는 부분만 100만 건당 부과합니다.

VPC resource

소비자는 service network에 추가한 resource당 시간 요금과 처리 GB 계단 요금, 제공자는 Resource Gateway 처리 GB당 요금을 냅니다.

공식 요금 페이지

API Gateway

API 유형마다 요청 단위로 요금을 냅니다. REST API와 HTTP API는 받은 요청 수, WebSocket API는 주고받은 메시지 수와 연결 시간으로 계산하며, 월 사용량이 많을수록 단가가 내려가는 계단식입니다. REST API에 캐시를 켜면 캐시 크기별 시간 요금이 붙습니다.

REST API

받은 API 호출 100만 건당. 월 누적 3억 3,300만 · 10억 · 200억 건에서 단가가 바뀝니다.

HTTP API

100만 건당. 요청 1건은 512 KB 단위로 계산하고, 월 3억 건을 넘으면 단가가 내려갑니다.

WebSocket

메시지 100만 건(32 KB 단위)과 연결 시간 100만 분을 따로 계산합니다.

Cache

REST API stage 캐시 크기(0.5–237 GB)별 시간당 요금입니다.

공식 요금 페이지

CloudFront

CloudFront는 엣지에서 사용자에게 나가는 데이터(DTO)와 HTTP/HTTPS 요청 수로 요금을 냅니다. 단가는 요청을 처리한 엣지 로케이션의 지역 그룹과 월 누적량으로 정해지며 리전과는 무관합니다. 사용량과 무관하게 월 정액으로 쓰는 flat-rate plan도 있습니다.

Data transfer out

엣지 → 인터넷 GB당. 지역 그룹별 7단 계단이며, 모든 그룹을 합쳐 매월 1 TB는 무료입니다.

Requests

HTTP와 HTTPS 요청을 1만 건 단위로 따로 셉니다. 매월 1,000만 건은 무료입니다.

Origin

엣지 → 오리진 전송(POST·PUT 등 업로드)은 GB당 별도 단가입니다. AWS 오리진에서 엣지로 오는 전송은 무료입니다.

Flat-rate plan

배포(distribution)당 월 정액에 CDN, WAF, DDoS 보호, Route 53 DNS 등이 포함되고 초과 요금이 없습니다.

공식 요금 페이지 (종량제) 공식 요금 페이지 (flat-rate)

Global Accelerator

accelerator마다 시간당 고정비가 붙고, 트래픽에는 표준 데이터 전송 요금 위에 DT-Premium이 GB당 추가됩니다. DT-Premium은 매시간 트래픽이 더 많은 방향(dominant direction)에만 부과합니다.

Fixed fee

accelerator가 존재하는 매시간(부분 시간 포함) 부과합니다. 리전과 무관합니다.

DT-Premium

엔드포인트가 있는 리전 그룹과 클라이언트가 접속한 edge location 그룹 조합으로 정해집니다.

공식 요금 페이지

Transit Gateway

attachment 시간당 요금과 Transit Gateway로 보내는 트래픽의 데이터 처리 GB당 요금입니다. Transit Gateway 자체에는 요금이 없고, peering attachment를 거치는 리전 간 트래픽에는 EC2 리전 간 전송 요금이 추가됩니다.

Attachment hour

VPC, VPN, Direct Connect gateway, Connect, peering attachment 모두 같은 단가입니다(예외는 각주).

Data processing

attachment에서 Transit Gateway로 들어오는 트래픽 기준입니다. peering attachment로 들어오는 트래픽은 처리 요금이 없습니다.

Multicast

multicast 수신 인스턴스가 받는 GB마다 데이터 처리 요금이 부과됩니다.

공식 요금 페이지

Cloud WAN

Core Network Edge(CNE) 시간당 요금, attachment·peering 시간당 요금, 데이터 처리 GB당 요금으로 구성됩니다. 리전 간·인터넷·Direct Connect 구간의 표준 데이터 전송 요금은 따로 붙습니다.

Core Network Edge

코어 네트워크 정책에 넣은 리전(edge location)마다 시간당 부과합니다.

Attachment · Peering

VPC, Connect, Site-to-Site VPN, Transit Gateway peering attachment마다 시간당 부과합니다.

Data processing

VPC·VPN attachment에서 Cloud WAN으로 보내는 트래픽 GB당 부과합니다.

공식 요금 페이지

PrivateLink

interface endpoint는 endpoint를 배치한 AZ마다 시간당 요금이 붙고, 처리한 데이터는 리전 단위 월 누적량에 따라 계단식으로 GB당 부과합니다. Gateway Load Balancer endpoint는 별도 단가입니다.

Interface endpoint

endpoint × AZ 수만큼 시간당 부과합니다. 3개 AZ에 두면 3배입니다.

Data processing

리전의 모든 interface endpoint 처리량을 합산해 계단을 적용합니다.

GWLB endpoint

endpoint 시간당 + 처리 GB당입니다. 뒤의 Gateway Load Balancer 요금은 별도입니다.

공식 요금 페이지

Direct Connect

요금은 포트 시간(port-hour)과 데이터 전송(DTO) 두 가지입니다. 포트 시간은 연결이 사용 가능한 상태인 동안 부과되며 일본 로케이션만 단가가 다릅니다. DTO는 AWS 리전에서 Direct Connect 로케이션 방향으로 나가는 트래픽에만 붙고, 들어오는 트래픽은 무료입니다.

Port hour

Dedicated는 AWS가, Hosted는 Direct Connect Partner가 프로비저닝합니다. 부분 시간도 1시간으로 계산합니다.

Data transfer out

소스 리전과 DX 로케이션이 속한 지역 그룹의 조합으로 GB당 단가가 정해집니다. Private VIF와 Public VIF 단가가 같습니다.

SiteLink

SiteLink를 켠 VIF는 VIF 시간당 요금과 DX 로케이션 간 GB당 전송 요금이 추가됩니다.

공식 요금 페이지

AWS Interconnect

Interconnect는 연결 하나마다 선택한 대역폭과 자동으로 정해지는 가격 Tier(1–5)에 따라 시간 요금을 냅니다. GB당 데이터 전송 요금은 없습니다. multicloud는 상대 클라우드(Google Cloud, OCI) 쪽 요금을 그 클라우드에 따로 냅니다.

Tier

multicloud는 트래픽이 출발하는 AWS 리전과 interconnect의 로컬 리전, last mile은 Interconnect metro와 가장 먼 AWS 리전의 거리로 정합니다. 가장 높은 Tier 하나만 적용합니다.

Hourly

연결을 만든 시점부터 삭제할 때까지 1시간 단위(올림)로 부과합니다.

Cloud WAN 연동

Direct Connect gateway를 Cloud WAN core network에 붙이면 가장 먼 CNE 기준으로 Tier가 올라갑니다.

공식 요금 페이지 (multicloud) 공식 요금 페이지 (last mile)

Site-to-Site VPN

Site-to-Site VPN은 VPN connection 시간당 요금이 기본이고, VPN에서 나가는 트래픽은 EC2 데이터 전송 요금을 따릅니다. Accelerated VPN은 여기에 connection당 Global Accelerator 2개의 고정비와 DT-Premium이 더해집니다.

VPN connection

터널 2개짜리 connection 1개 단위입니다. 표준(최대 1.25 Gbps/터널)과 Large(5 Gbps/터널) 단가가 다릅니다.

Accelerated VPN

VPN connection + Global Accelerator 고정비 × 2 + DT-Premium(GB당). 비가속 VPN에는 Global Accelerator 요금이 없습니다.

VPN Concentrator

여러 지사(site)를 하나의 Concentrator에 붙이고 Concentrator 시간과 site 시간을 따로 냅니다.

공식 요금 페이지

Client VPN

Client VPN은 endpoint에 연결한 subnet association 시간과 활성 클라이언트 연결 시간을 함께 냅니다. VPN을 거쳐 나가는 트래픽에는 EC2 데이터 전송 요금이 붙습니다.

Endpoint association

Client VPN endpoint에 연결한 subnet 1개당 시간 요금입니다.

Connection

동시에 연결된 클라이언트 1개당 시간 요금입니다.

공식 요금 페이지

Amazon VPC

VPC 자체에는 요금이 없고, 그 안에서 쓰는 NAT gateway, public IPv4 주소, IPAM, Traffic Mirroring, Encryption Controls 같은 기능과 데이터 전송에 요금이 붙습니다. 리전 간 · AZ 간 · 인터넷 데이터 전송 단가도 이 탭에 모았습니다.

NAT gateway

gateway가 존재하는 시간과 처리한 GB로 냅니다. regional NAT gateway는 동작 중인 AZ마다 시간 요금이 붙습니다.

Public IPv4

사용 중이든 유휴 상태든 public IPv4 주소 1개당 시간 요금입니다. Elastic IP도 같습니다.

IPAM

Free Tier는 무료이고, Advanced Tier는 IPAM이 관리하는 활성 IP 주소 1개당 시간 요금입니다.

Data transfer

리전 간 전송은 출발 리전이, AZ 간 전송은 양방향 각각 GB당 냅니다. AWS로 들어오는 데이터(DTI)는 무료입니다.

공식 요금 페이지 (VPC) 공식 요금 페이지 (데이터 전송)

Route 53

Route 53은 hosted zone 월 요금, DNS 쿼리 수, health check 수가 기본입니다. VPC 쪽 기능인 Resolver endpoint, Resolver DNS Firewall, Profiles는 리전별 요금입니다. 도메인 등록 요금은 TLD마다 달라 공식 요금 페이지의 목록을 참고하세요.

Hosted zone

zone당 월 요금(일할 계산 없음). 첫 25개 이후 단가가 내려갑니다. zone당 레코드 1만 개를 넘으면 레코드당 월 요금이 붙습니다.

Queries

라우팅 정책별 100만 건당. 월 10억 건을 넘으면 절반 단가입니다. AWS 리소스를 가리키는 alias 레코드 쿼리는 무료입니다.

Health check

AWS 엔드포인트와 그 밖의 엔드포인트 단가가 다르고, HTTPS · 문자열 매칭 같은 옵션은 기능당 추가됩니다.

Resolver

endpoint ENI 시간당 요금과 endpoint를 지나는 쿼리 100만 건당 요금입니다. VPC 안에서 바로 해석되는 쿼리는 무료입니다.

공식 요금 페이지

Network Firewall

firewall endpoint가 있는 AZ마다 시간 요금, endpoint가 처리한 트래픽 GB당 요금을 냅니다. TLS inspection을 쓰면 Advanced Inspection 시간 요금, active threat defense managed rule group을 켜면 GB당 요금이 추가됩니다.

Endpoint

리전 × AZ마다 시간 요금입니다. 같은 firewall을 다른 VPC에 붙인 secondary endpoint는 더 낮은 단가입니다.

Traffic processing

endpoint를 지난 트래픽 GB당입니다. 출발지 · 목적지와 무관합니다.

Advanced Inspection

TLS inspection을 쓰는 동안 AZ당 추가 시간 요금입니다. 별도 GB 요금은 없습니다.

NAT gateway 면제

같은 경로의 NAT gateway는 Network Firewall endpoint 시간 · GB만큼 NAT gateway 시간 · GB 요금이 1:1로 면제됩니다.

공식 요금 페이지

AWS WAF

web ACL과 규칙(rule · rule group)마다 월 요금(시간 단위 일할), 검사한 요청 100만 건당 요금을 냅니다. Bot Control, Fraud Control, Anti-DDoS 같은 AWS Managed Rules 기능은 구독 월 요금과 요청 요금이 따로 붙습니다.

Web ACL · Rule

web ACL 1개, 규칙 또는 rule group 1개마다 월 요금입니다. 직접 만든 rule group은 안의 규칙도 각각 셉니다.

Requests

web ACL이 검사한 요청 100만 건당입니다. 기본 1,500 WCU를 넘거나 본문 검사 한도를 늘리면 단가가 오릅니다.

Managed features

Bot Control · Fraud Control · Anti-DDoS는 web ACL당 월 구독료와 요청 요금입니다.

CAPTCHA · Challenge

CAPTCHA 시도 1만 건당, Challenge 응답 100만 건당 부과합니다.

공식 요금 페이지

AWS Shield

Shield Standard는 모든 AWS 고객에게 추가 비용 없이 적용됩니다. Shield Advanced는 1년 약정 구독으로 payer 계정당 월 요금을 내고, 보호 대상 리소스에서 나가는 데이터(DTO)에 리소스 유형별 사용 요금이 추가됩니다.

Shield Standard

L3 · L4 DDoS 기본 보호. 신청이나 추가 요금이 없습니다.

Advanced 구독

Organization의 payer 계정 기준 월 고정 요금이고, 1년 약정이 필요합니다.

Advanced DTO

CloudFront · Global Accelerator(글로벌)와 ELB · Elastic IP(리전별)에서 나가는 GB당 사용 요금입니다. Route 53은 추가 요금이 없습니다.

WAF 포함

보호 리소스의 WAF web ACL · 규칙 · 요청(기본 WCU)은 월 500억 건까지 구독에 포함됩니다.

공식 요금 페이지

Firewall Manager

Firewall Manager는 보호 정책(protection policy) 1개를 리전 1개에 적용할 때마다 월 요금을 냅니다. 정책이 만든 WAF web ACL, Network Firewall endpoint, DNS Firewall rule group, AWS Config rule은 각 서비스 요금으로 따로 청구됩니다.

Policy

정책 × 리전 단위 월 요금입니다. 대부분 리전에서 정책 유형과 무관하게 같은 단가입니다.

Shield Advanced 고객

Shield Advanced 구독자는 Firewall Manager 정책 요금이 포함되어 있습니다(AWS Config rule 요금은 별도).

연관 요금

AWS Config rule, 정책이 만든 각 서비스 리소스는 해당 서비스 단가로 부과합니다.

공식 요금 페이지

VPC Flow Logs

Flow log를 만들거나 켜는 데는 요금이 없고, 생성된 로그를 보내는 곳(CloudWatch Logs, S3, Data Firehose)에 따라 CloudWatch vended logs 요금을 GB당 냅니다. 월 누적량에 따라 4단 계단입니다. 저장 · 조회 요금은 각 대상 서비스 요금이 따로 붙습니다.

CloudWatch Logs

Standard와 Infrequent Access 로그 클래스 단가가 다릅니다. 수집(ingestion) 요금이고 저장 요금은 별도입니다.

Amazon S3

S3로 전달하는 GB당 요금입니다. Apache Parquet 변환을 켜면 GB당 변환 요금이 추가됩니다.

Data Firehose

Firehose로 전달하는 GB당 요금입니다. Firehose 자체 요금은 별도입니다.

공식 요금 페이지 (CloudWatch · Vended logs)

Network Flow Monitor

Network Flow Monitor는 agent를 설치해 모니터링하는 리소스(EC2 인스턴스, EKS 노드 등) 1개당 시간 요금과, monitor가 게시하는 CloudWatch 지표 요금으로 구성됩니다. 함께 쓰는 Network Synthetic Monitor는 모니터링 리소스당 시간 요금입니다.

Monitored resource

agent가 흐름 데이터를 보내는 리소스 1개당 시간 요금입니다. 처음 12개월은 월 7,300 리소스-시간(리소스 10개)이 무료입니다.

Metrics

monitor가 게시하는 지표는 CloudWatch 사용자 지정 지표 단가(지표당 월)로 부과합니다.

Synthetic Monitor

온프레미스 경로를 probe로 측정하는 monitor의 모니터링 리소스당 시간 요금입니다.
