AWS Transit Gateway · Regional routing hub

Route your VPCs and on-premises networks through a single hub

AWS Transit Gateway is a managed router that connects VPCs, Site-to-Site VPN, Direct Connect gateways, and SD-WAN appliances in a Region at a single point. Transit Gateway route tables decide which attachments can talk to each other.

Why Transit Gateway

The more VPCs you add, the harder a peering mesh is to manage

VPC peering does not support transitive routing, so the number of connections grows quickly as VPCs are added. Transit Gateway brings every connection into a hub and manages routing policy in one place.

Hub

Hub and spoke

Attach each VPC, VPN, Direct Connect, and SD-WAN connection once, and they communicate with each other through the hub.

Segment

Segmentation with route tables

Split routing domains such as production, development, and shared services, and propagate only the routes you need to limit what can communicate.

Share

Multi-account sharing

Share the Transit Gateway with other accounts through AWS RAM. Each account attaches its own VPCs, while the network team manages routing.

Association & propagation

One association, many propagations

Each attachment is associated with one route table and looks up destinations there. At the same time, it can propagate its routes to multiple route tables. The combination of these two settings is your network segmentation policy.

Attachment rtb-prod rtb-dev rtb-shared
VPC prod10.10.0.0/16 A – P
VPC dev10.30.0.0/16 – A P
VPC shared10.20.0.0/16 P P A
DX gateway172.16.0.0/12 P P AP
A

Association

Determines which route table is used to look up packets arriving from an attachment. An attachment can be associated with only one route table.

P

Propagation

Automatically installs an attachment's routes in a route table. VPCs propagate their CIDRs; VPN, DX gateway, and Connect propagate routes learned over BGP. Peering uses static routes.

Result: The prod and dev tables have no routes to each other, so the two VPCs cannot communicate. Both VPCs can reach the shared services VPC and on-premises.

Features

Key features

Stateful inspection

Appliance mode

Enable it on the inspection VPC attachment so both directions of a flow pass through the appliance in the same AZ. This prevents asymmetric paths through stateful firewalls.

Native firewall

Network Firewall attachment

Attach AWS Network Firewall directly as a Transit Gateway attachment, with no separate VPC and subnets to host firewall endpoints.

Multi-region

Inter-Region peering

Peer with Transit Gateways in other Regions or accounts. Inter-Region traffic travels over the AWS backbone encrypted with AES-256.

SD-WAN

Transit Gateway Connect

Connect SD-WAN appliances with GRE tunnels and BGP, using a VPC or Direct Connect as the transport. Up to 5 Gbps per GRE peer.

Many sites

VPN Concentrator

Terminates Site-to-Site VPN from up to 100 branch sites on a single attachment. Up to 100 Mbps per site and 5 Gbps in total; BGP routing only.

One to many

Multicast

Routes multicast between VPCs using IGMPv2 or static group membership. Subnets are grouped per multicast domain, and multicast is enabled on a new Transit Gateway.

Getting started

Steps to set up Transit Gateway

  1. STEP 1

    Create the Transit Gateway

    Choose the ASN and decide whether to use default route table association and propagation.

  2. STEP 2

    Create attachments

    Attach VPCs by specifying one subnet per AZ. Attach VPN and DX gateways as well.

  3. STEP 3

    Design route tables

    Create a table per domain and configure association and propagation for each attachment.

  4. STEP 4

    Add VPC routes

    Add routes targeting the Transit Gateway to each VPC subnet route table.

  5. STEP 5

    Verify flows

    Use Transit Gateway Flow Logs to confirm traffic follows the intended path.

Pricing

Cost components

Transit Gateway pricing is based on the number of attachments and their hours, plus the amount of data sent to the Transit Gateway. VPN, Direct Connect, and inter-Region transfer are charged separately.
